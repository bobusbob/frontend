# SummaVideo

Фронтенд сервиса суммаризации видео. Бэкенда нет: кнопка показывает сценарий обработки и пример карточки. Ссылка и файл остаются в браузере.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Подключение анализа — в `src/lib/summarize.ts`, функция `createSummary`.
