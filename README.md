# SummaVideo

Веб-сервис, который помогает не смотреть ролик целиком.

На сайте два разных режима:

| Режим | Что получает пользователь | Где считается |
|---|---|---|
| **YouTube-ссылка** | Краткая выжимка: тезисы, главы и таймкоды | На сервере. Транскрипт берёт [Supadata](https://supadata.ai), текст собирает Gemini |
| **Видео с компьютера** | Полный текст речи, без сокращения смысла | Только на этом компьютере, программой faster-whisper. В облако файл не уходит |

Готовую выжимку YouTube можно скопировать или скачать в Markdown. Полную расшифровку файла можно скопировать или скачать в Word (`.docx`).

Сайт открывается на [http://localhost:3000](http://localhost:3000). Регистрация не нужна.

## Требования

- Node.js 20 или новее и npm. Сайт лежит в папке `video-summarizer/convert Video`.
- Python 3.12, если нужна расшифровка файла с диска. Программа лежит в папке `video-summarizer/transcribe`.
- Ключи `SUPADATA_API_KEY` и `GEMINI_API_KEY` только для режима YouTube. Для файла с компьютера ключи не используются.
- Для YouTube модель Gemini должна быть доступна из вашей страны. Если API отвечает `User location is not supported`, выжимка с этой машины не соберётся.

## Запуск сайта

```bash
cd "video-summarizer/convert Video"
npm install
```

Скопируйте `.env.example` в `.env.local` и впишите ключи:

```text
SUPADATA_API_KEY=
GEMINI_API_KEY=
```

Файл `.env.local` не коммитится.

```bash
npm run dev
```

После первой записи ключей сервер нужно перезапустить: Next.js читает `.env.local` при старте.

Откройте [http://localhost:3000](http://localhost:3000).

## Запуск расшифровки файла

Это отдельная программа. Она слушает только `http://127.0.0.1:8765` и принимает видео с сайта на том же компьютере.

Один раз создайте окружение и поставьте распознавание речи. Команды для Windows, из корня репозитория:

```bash
cd video-summarizer/transcribe
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команда `py` недоступна, используйте тот `python.exe`, который у вас версии 3.12. В `requirements.txt` пакет `faster-whisper` и совместимая с ним версия `av` (ниже 15). Более новый PyAV ломает чтение видео.

Запуск:

```bash
start.bat
```

Либо напрямую:

```bash
.venv\Scripts\python.exe -u server.py
```

В консоли должна появиться строка `Расшифровка слушает http://127.0.0.1:8765`. Если открыть этот адрес в браузере, это не сайт, а служебная страница: там написано, что программа запущена. Сам интерфейс по-прежнему на порту 3000.

При первом ролике модель `small` скачивается один раз (несколько сотен мегабайт). Дальше распознавание работает без интернета. На обычном процессоре длинное видео может обрабатываться примерно столько же, сколько оно длится.

## Как пользоваться

### Ссылка YouTube

1. Вставьте `youtube.com/watch`, `youtu.be` или Shorts.
2. Дождитесь превью ролика.
3. Нажмите **Создать краткое содержание**.

На экране три шага: получение транскрипта, распознавание и сборка выжимки. Готовая карточка содержит 3–5 тезисов и главы. Таймкод главы открывает ролик YouTube на этой секунде. Время в главах сверяется с кусками транскрипта, а не придумывается моделью.

Поддерживаемые адреса: `youtube.com/watch?v=`, `youtu.be/`, Shorts, embed и live.

### Видео с компьютера

1. Запустите локальную программу из раздела выше.
2. На сайте откройте вкладку **Видео с компьютера**.
3. Перетащите файл или выберите его. Форматы: MP4, MOV, WebM, MKV, до 500 МБ.
4. Нажмите **Расшифровать полностью**.

Появится весь распознанный текст с таймкодом в начале каждой фразы. Кнопка **Скачать Word** сохраняет этот текст в `.docx`. Это не краткий пересказ.

Одновременно считается только один файл. Пока идёт расшифровка, второй запрос получит отказ и попросит подождать.

## Как устроена выжимка YouTube

1. Сервер проверяет, что ссылка ведёт на YouTube, и приводит её к виду `https://www.youtube.com/watch?v=ID`.
2. `GET https://api.supadata.ai/v1/transcript` с параметрами `text=false`, `mode=auto`, `lang=ru`. Куски транскрипта приходят со смещением в миллисекундах. Если ролик большой, Supadata отвечает номером задачи, и сервер опрашивает `GET /v1/transcript/{jobId}`.
3. Параллельно `GET /v1/metadata` даёт название, автора, обложку и длительность. Если метаданные не пришли, карточка всё равно собирается.
4. Текст кусков уходит в Gemini, модель `gemini-4-hydrogen`, одним запросом `interactions.create`. Ответ — JSON с тезисами и главами.
5. Сервер оставляет только те секунды, которые есть в транскрипте (допуск 20 секунд), и отдаёт карточку на страницу потоком событий.

Ключи передаются только с сервера. В браузер они не попадают.

История трёх последних выжимок YouTube хранится в `localStorage` браузера. Базы данных у сервиса нет.

## Структура репозитория

```text
video-summarizer/
  convert Video/          сайт Next.js
    src/app/api/summarize маршрут выжимки YouTube
    src/server/           Supadata, промпт Gemini, сборка карточки
    src/lib/transcribe.ts клиент локальной расшифровки
    .env.example          имена переменных без секретов
  transcribe/             локальная программа faster-whisper
    server.py             приём файла и поток текста
    start.bat             запуск на Windows
    requirements.txt
  BACKEND_PLAN.md         подробный план режима YouTube
  PRD_UI_Design.md        описание интерфейса
```

## Переменные окружения

| Переменная | Где нужна | Зачем |
|---|---|---|
| `SUPADATA_API_KEY` | `.env.local` сайта | Транскрипт и метаданные YouTube |
| `GEMINI_API_KEY` | `.env.local` сайта | Текст выжимки |

Для файла с компьютера переменные не задаются.

## Ограничения

- Файл с диска не анализируется на Vercel и не отправляется в Supadata или Gemini. Без запущенного `server.py` кнопка «Расшифровать полностью» сообщит, что локальная программа не запущена.
- Supadata может ответить `429`, если лимит ключа исчерпан. На экране будет просьба повторить позже.
- Пустой транскрипт или ролик без речи показывает сообщение, что речь не найдена.
- Неверная ссылка не уходит во внешние API.
- Выжимка пишется по-русски, даже если ролик на другом языке. Имена и числа сохраняются.

## Проверка, что всё живое

Сайт:

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3000/
```

Ожидается `200`.

Локальная расшифровка:

```bash
curl -s http://127.0.0.1:8765/health
```

Ожидается `{"ok": true, "busy": false}`.
